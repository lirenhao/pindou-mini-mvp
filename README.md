# 拼豆图纸生成器（微信小程序 MVP）

## 功能
- 从相册或相机选择图片，拖动并放大，预览实际入图范围
- 设置图纸宽度、高度（5–100 格）和颜色数量（2–32 色）
- 透明区域留空，不计入豆子
- 聚类后就近匹配 MARD 291 参考色，可选渐变抖动
- 生成带网格和格子编号的图纸。预览默认看整张，可双指放大；导出的 PNG 底部附色号对照
- 统计每种颜色的 MARD 色号、RGB、HEX 和豆子数量
- 导出 PNG 到相册；调用前会走微信隐私授权

## 导入微信开发者工具
1. 解压项目。
2. 打开微信开发者工具，选择“导入项目”。
3. 目录选择本项目根目录。
4. AppID 需使用已配置《用户隐私保护指引》的小程序。测试号通常不能声明隐私接口，选图会失败。
5. 在 `project.config.json` 中将 `appid` 替换成自己的 AppID（可选）。

## 说明
- 色卡数据来自 [HansBug/pindou-color-data](https://github.com/HansBug/pindou-color-data) 的 `mard-291-github`（MIT）。RGB 是屏幕参考值，买豆时请用色号对照实物色卡。
- 图片处理全部在本地完成，没有后端服务。
- 图纸最多 100×100 格。导出时会限制图片像素量，避免超过微信画布的大小上限。
- 开发者工具里选图也会校验隐私指引。请在公众平台「设置 → 用户隐私保护指引」声明：收集你选中的照片或视频信息、访问你的摄像头、相册（仅写入）。保存后约 5 分钟生效。
