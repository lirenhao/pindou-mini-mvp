# 拼豆图纸生成器（微信小程序 MVP）

## 功能
- 从微信相册选择图片
- 设置图纸宽度、高度（5–100 格）和颜色数量（2–32 色）
- 使用轻量级 RGB 聚类进行颜色量化
- 生成带网格的拼豆图纸预览
- 统计每种颜色的 RGB、HEX 和豆子数量
- 导出 PNG 到微信临时文件，并调用保存图片能力

## 导入微信开发者工具
1. 解压项目。
2. 打开微信开发者工具，选择“导入项目”。
3. 目录选择本项目根目录。
4. AppID 可先使用测试号；需要真机保存图片时，按开发者工具提示配置权限。
5. 在 `project.config.json` 中将 `appid` 替换成自己的 AppID（可选）。

## 说明
- 当前颜色库是由原图自动聚类得到的自定义 RGB 色，不对应任何商业拼豆品牌色卡。
- 图片处理全部在本地完成，没有后端服务。
- MVP 为保持兼容性，图纸尺寸最多 100×100 格；导出 PNG 使用每格 12 像素，含网格线。
